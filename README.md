# E-Commerce Data Analysis & Predictive Modelling

## Project Overview
An end-to-end E-Commerce Data Analytics project focused on evaluating business performance, customer purchasing behaviour, website conversion rates, and revenue trends.

The project combines SQL, Python, Power BI, and Machine Learning to transform raw transactional data into meaningful business insights.

## Tools & Technologies
- **SQL Server:** Data extraction, joins, CTEs, aggregations, and business analysis
- **Python:** Pandas, NumPy, Matplotlib, Scikit-learn
- **Power BI:** Interactive dashboards and KPI tracking
- **Machine Learning:** Linear Regression and Logistic Regression

## Business Objectives
- Analyze sales and revenue performance
- Track website traffic and customer conversions
- Identify product and marketing channel performance
- Analyze order trends, profitability, and refunds
- Develop predictive models to support business decisions

## Dataset
Analyzed six interconnected e-commerce datasets covering website sessions, pageviews, orders, products, and refunds.

## Project Workflow
1. **Data Preparation:** Examined and validated data from multiple related tables.
2. **SQL Analysis:** Used joins, CTEs, aggregations, and analytical queries to study business KPIs.
3. **Python Analysis:** Performed exploratory data analysis and visualizations.
4. **Power BI Dashboard:** Developed interactive reports to monitor sales, website performance, and business trends.
5. **Predictive Modelling:** Applied Linear Regression for order-value prediction and Logistic Regression for purchase conversion analysis.

## Machine Learning
- Linear Regression for order-value prediction
- Logistic Regression for purchase conversion prediction
- Evaluated models using suitable regression and classification metrics
